01

활성화 함수Activation functions

퍼셉트론의 f(·) 자리에 들어가는 함수입니다. 계단 대신 다른 함수를 쓰면 학습이 쉬워지고, 층을 쌓는 의미가 생깁니다.a = f(z)

1왜 필요한가

점수 z를 받아 다음 층으로 보낼 값 a를 만드는 함수입니다. 퍼셉트론의 계단 함수에는 두 가지 문제가 있습니다. 첫째, 거의 모든 곳에서 기울기가 0이라 "얼마나 고쳐야 하는지" 신호를 주지 못합니다. 둘째, 반대로 f를 아예 빼 버리면(f(z) = z) 층을 아무리 쌓아도 결국 직선 하나와 같아집니다. 그래서 기울기가 살아 있고, 어딘가에서 꺾이는 함수가 필요합니다.

입력점수 z (실수 하나)
출력a = f(z)
핵심 조건꺾임 + 기울기

쉽게 말하면조명 스위치와 조광기의 차이입니다. 계단 함수는 켜짐/꺼짐 스위치라 "조금 더 밝게"라는 말을 알아듣지 못합니다. 시그모이드는 돌리는 만큼 밝기가 바뀌는 조광기이고, ReLU는 "0 아래로는 꺼 두고, 위로는 돌린 만큼 켜는" 조광기입니다.

2함수 탐색기 · 모양과 기울기를 함께 보기

함수를 골라 보세요. 실선은 f(x), 점선은 기울기 f′(x)입니다. 기울기가 0에 붙어 있는 구간에서는 학습 신호가 사라진다는 점을 눈여겨보세요.

f(x)f′(x) 기울기 (점선)지금 x
3아홉 가지를 한 표로
이름수식출력 범위기울기의 특징주로 쓰는 곳
계단 (Step)1 if x ≥ 0, else 0{0, 1}어디서나 0 → 경사하강 불가원래 퍼셉트론
선형 (Identity)f(x) = x(−∞, ∞)항상 1, 꺾임 없음출력층 (숫자 맞히기, 회귀)
시그모이드1 / (1 + e−x)(0, 1)최대 0.25, 양 끝에서 0에 가까움출력층 (이진 분류 확률)
tanhtanh(x)(−1, 1)최대 1, 양 끝에서 0에 가까움은닉층, 순환 신경망
ReLUmax(0, x)[0, ∞)양수에서 1, 음수에서 0은닉층 (가장 흔함)
Leaky ReLUx if x > 0, else αx(−∞, ∞)음수에서도 α만큼 남음은닉층 (ReLU가 죽을 때)
ELUx if x > 0, else α(ex − 1)(−α, ∞)음수 쪽이 부드럽게 줄어듦은닉층
Swish (SiLU)x · σ(x)약 [−0.278, ∞)부드럽고, 0 근처에서 살짝 음수은닉층 (이미지 모델 등)
GELUx · Φ(x)약 [−0.17, ∞)Swish와 비슷하게 부드러움은닉층 (트랜스포머, GPT·BERT)

σ는 시그모이드, Φ는 표준정규분포의 누적분포함수(평균 0, 표준편차 1인 종 모양 분포에서 x 이하일 확률)입니다. Leaky ReLU의 α는 보통 0.01이지만, 탐색기에서는 눈에 보이도록 0.1로 그렸습니다. ELU는 α = 1입니다.

4소프트맥스 · 점수를 확률로 바꾸기

클래스가 셋 이상일 때(정상 / 스팸 / 광고) 출력층에 씁니다. 점수를 ez로 모두 양수로 만든 뒤, 합으로 나눠 합이 1이 되게 합니다. 슬라이더로 점수를 바꿔 보세요.

softmax(zᵢ) = ezᵢ / Σⱼ ezⱼ
5해석

출력층은 답의 모양에 맞춰 고릅니다. 스팸일 확률 하나가 필요하면 시그모이드, 여러 클래스의 확률이 필요하면 소프트맥스, 집값 같은 숫자가 필요하면 선형 함수입니다.

은닉층은 학습이 잘되는 쪽으로 고릅니다. 시그모이드와 tanh는 입력이 크거나 작으면 기울기가 0에 가까워져, 층이 깊을수록 앞쪽 층에 학습 신호가 거의 전달되지 않습니다(기울기 소실). ReLU는 양수 쪽 기울기가 늘 1이라 이 문제가 적고 계산도 빨라 가장 널리 쓰입니다.

ReLU는 음수 쪽 기울기가 0이라, 어떤 뉴런이 늘 음수만 받으면 영영 배우지 못하는 "죽은 ReLU"가 생길 수 있습니다. Leaky ReLU, ELU, Swish, GELU는 음수 쪽에도 작은 기울기를 남겨 이것을 줄인 변형입니다.

층을 쌓으면 XOR이 풀린다A hidden layer folds the plane

1편에서 퍼셉트론 하나로 풀지 못한 XOR을, 은닉 뉴런 두 개와 ReLU 하나로 풉니다. 꺾임이 없으면 왜 안 되는지도 함께 봅니다.

하루

종이를 접으니까 대각선에 있던 점이 한쪽으로 모였어요!

1은닉 뉴런 두 개로 XOR 풀기

"링크나 느낌표 중 하나만 있으면 스팸"이라는 1편의 이상한 규칙입니다. 은닉층에 뉴런 두 개를 두고, 출력은 그 둘을 다시 더합니다. 가중치는 원리를 보이려고 손으로 정했습니다(학습 결과가 아닙니다).

h₁ = f(x₁ + x₂),   h₂ = f(x₁ + x₂ − 1),   출력 = h₁ − 2h₂  → 0.5 이상이면 스팸
활성화 f
입력 평면 (x₁, x₂)
은닉 평면 (h₁, h₂) · 점선 h₁ − 2h₂ = 0.5

2해석 · 층을 쌓는다 = 평면을 접는다

출력 뉴런 하나는 여전히 직선 하나만 긋습니다. 달라진 것은 그 직선이 그어지는 평면입니다. 은닉층은 입력 평면을 은닉 평면으로 옮기는데, ReLU가 음수를 0으로 자르는 순간 평면이 접히고, 입력에서 대각선에 있던 점들이 한쪽으로 모입니다.

꺾지 않으면 은닉층은 평면을 늘리고 돌리기만 할 뿐 접지 못합니다. 그래서 네 점이 한 줄로 서고, 마지막 직선은 정상·스팸·정상 순서를 가를 수 없습니다. 이렇게 퍼셉트론을 층으로 쌓고 사이에 활성화 함수를 둔 것을 다층 퍼셉트론(MLP)이라고 부릅니다. 손으로 정한 이 가중치를 데이터로 찾아내는 방법이 3편의 경사하강법입니다.

2해석 · 꺾임은 모양을 바꾸지, 정보를 만들지 않는다

선형을 고르면 은닉 뉴런이 8개여도 경계가 곧은 직선입니다. ReLU나 tanh를 고르면 경계가 휘거나 꺾입니다. 그런데 어려운 세트의 시험 정확도는 어떤 함수든 기준선(0.667) 근처에 머뭅니다.

이유는 데이터에 있습니다. 링크 3개·느낌표 2개짜리 뉴스레터와, 똑같이 링크 3개·느낌표 2개짜리 피싱 메일은 이 평면에서 같은 점입니다. 경계를 아무리 구불구불하게 그어도 같은 점의 두 메일을 가를 수는 없습니다. 활성화 함수가 푸는 것은 XOR 같은 모양의 문제이고, 겹침은 새 정보(특성)가 있어야 풀립니다. 4편에서 글자 수를 더해 이 벽을 넘습니다.

뜻어떤 실수든 0과 1 사이 값으로 바꾸는 S자 함수 σ(z) = 1/(1 + e⁻ᶻ).
ReLU
비유반쯤 열린 수문. 물(값)이 음수면 막고, 양수면 그대로 흘려보냅니다.
뜻max(0, z). 은닉층에서 가장 널리 쓰이는 활성화 함수.
소프트맥스
비유반장 선거의 득표수를 득표율로 바꾸기. 모든 후보의 득표율을 더하면 100%가 됩니다.
뜻클래스별 점수를 합이 1인 확률로 바꾸는 함수. e^zᵢ / Σ e^zⱼ.
기울기 소실
비유긴 줄의 귓속말 게임. 뒤로 전할수록 목소리가 작아져 맨 앞사람에게는 거의 들리지 않습니다.
뜻층을 거슬러 기울기를 전할 때마다 작은 수가 곱해져, 앞쪽 층의 기울기가 0에 가까워지는 현상.
층 쌓기
은닉층
비유공장 안쪽의 중간 공정. 손님(입력)과 완제품(출력) 사이에서 보이지 않게 부품을 가공합니다.
뜻입력층과 출력층 사이에 있는 층. 여기서 쓰는 활성화 함수가 망의 표현력을 좌우합니다.
다층 퍼셉트론
비유여러 단계의 심사. 1차 심사위원들의 점수를 2차 심사위원이 다시 받아 판단합니다.
뜻퍼셉트론(뉴런)을 층으로 쌓고 층 사이에 활성화 함수를 둔 신경망. MLP라고도 부릅니다.
XOR
비유"둘 중 하나만" 규칙. 커피와 차 가운데 딱 하나만 마시면 통과, 둘 다거나 둘 다 아니면 탈락입니다.
뜻두 입력이 서로 다를 때만 1인 논리 연산. 직선 하나로 나눌 수 없어 퍼셉트론 하나로는 풀지 못합니다.
기준선
비유찍기 점수. 문제를 읽지 않고 가장 흔한 답 하나만 골랐을 때 받는 점수입니다.
뜻학습 데이터에서 더 많은 쪽 하나로만 답했을 때의 시험 정확도. 모델 점수는 이것보다 높아야 의미가 있습니다.

  1. 활성화 함수는 점수 z를 꺾어 다음 층으로 보냅니다. 은닉층은 ReLU, 출력층은 답의 모양에 맞춥니다.
  2. 꺾임이 있어야 층을 쌓는 의미가 생기고, 평면을 접어 XOR 같은 모양을 풉니다.
  3. 꺾임은 모양의 문제를 풀 뿐, 같은 자리에 겹친 데이터는 새 정보가 있어야 풀립니다.
